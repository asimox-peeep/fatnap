# فِطنة V7

نسخة مطوّرة من لعبة فِطنة تعمل كصفحة ويب ويمكن نشرها على GitHub Pages.

## التحديثات في V7
- شاشة افتتاحية سينمائية ملء الشاشة مع شعار SPON TEAM مضمّن داخل HTML لضمان ظهوره حتى عند رفع الملف وحده.
- زر START للدخول إلى اللعبة بعد انتهاء شاشة البداية.
- لعبة شطرنج مع وضع اللعب ضد بوت بسيط أو لاعبين على الجهاز نفسه.
- زر ملء الشاشة للشطرنج ولوحة 8×8 بخانات مربعة متساوية.
- وضع ألغاز «صح أم خطأ» بالإضافة إلى الاختيارات المتعددة.
- عرض عدد النجوم ومضاعف الأرباح.
- استخدام الجواهر 💎 بدلاً من العملات في واجهة اللعبة. الرصيد السابق محفوظ ويحوّل تلقائياً إلى جواهر.

## ملاحظات
- بوت الشطرنج الحالي يستخدم نقلات قانونية أساسية حسب حركة القطع، لكنه ليس محرك شطرنج كاملاً: لا يتحقق بعد من كش ملك، التعادل، التبييت أو الأخذ بالتجاوز.
- اللعب عبر الإنترنت بين أجهزة مختلفة يحتاج إلى خدمة خلفية حقيقية، ولم يتم الادعاء بأنه يعمل دون إعدادها.
- بيانات التقدم تُحفظ محلياً على الجهاز؛ مسح بيانات المتصفح قد يحذفها.

## النشر
ارفع محتويات مجلد `fetna-game` إلى جذر مستودع GitHub، ثم فعّل GitHub Pages من Settings → Pages → Deploy from a branch → main → /(root).
